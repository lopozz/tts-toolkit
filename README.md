# tts-toolkit
Utilities to run speech-to-text models.

The toolkit currently focuses on vLLM-hosted TTS models exposed through an
OpenAI-compatible audio endpoint.

## Installation

```bash
uv venv
source .venv/bin/activate
uv pip install -e .
```

If you install in editable mode, the library is imported as:

```python
import stt_toolkit
```
